# v2.1.0 — 变成能装的插件

装不上不是配置问题：2.0 的仓库里根本没有 `package.json`，也没有 `dsh.bundle.patch` 声明，插件管理器自然报「这个包没有声明组合包」。这一版把这层补上。

## 变更

- **可安装**：新增 `package.json`（含 `dsh.bundle.patch`）、`cordis.patch.yml` 名册、Host 半区 `lib/index.js`
- **工具**：注册 `input_gate(text, source?)`，返回 `verdict / codes / truncated / droppedChars / text`
- **规则移植**：`lib/gate.js` 与 `gate.py` 同规则，两份各有断言
- **fail closed**：检测出错返回 `ok: false` + `verdict: reject`，不把原文当通过结果交出去
- **不让宿主起不来**：配置写错只记 error 并跳过注册，`tools` 服务缺失只记 warn
- **测试**：新增 `tests/gate.test.mjs`（`node --test`，零依赖）

## 升级

```bash
cd ~/.dsh/profiles/desktop
pnpm add github:NotFatJustRound/input-gate
```

然后重启一次 DSH。配置在 `cordis.patch.yml` 的 `config` 里，字段见 README 的策略表。

## 验证

```bash
node --test tests/gate.test.mjs
python -m unittest discover -s tests -v
```

## 已知问题

- JS 与 Python 是同规则的两次手写，不共享代码；改规则要两边一起改。
- 关键词匹配必然漏，白名单只到域名，`quarantine` 的内容仍然进上下文。详见 README「已知局限」。
