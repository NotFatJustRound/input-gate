# 发布笔记

仓库里每个带 tag 的版本，发布说明都放这里：`docs/releases/<tag>.md`。

- 打 tag 之前先确认 `package.json` 的 `version` 与 tag 一致（`v2.1.0` ↔ `2.1.0`）。
- 发 Release 时正文直接取本目录对应文件，不要另写一份。
- 手上只有建仓、写文件、提 issue 的工具，**打 tag 和发 Release 需要人在 GitHub 界面上点**。
